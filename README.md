# ClassiNy2（クラシニー2）

**メールの振り分け感覚で、デスクトップやダウンロードフォルダを全自動で美しく。**

名作ファイル自動振り分けツール『ClassiNy』が、現代のPC環境に合わせてシステムをゼロから構築し直し、待望の後継ソフト『ClassiNy2』として正統進化しました。還暦を迎えた開発者が、熱意を込めて1行ずつ丁寧に書き上げています。

---

## 🚀 主な特徴と前作からの進化点

- **直感的なルール設定**
  「拡張子が〇〇なら✕✕フォルダへ」「ファイル名に〇〇が含まれていたら△△へ」といった振り分けルールを、メールのフィルターを作る感覚でササッと直感的に作成できます。
- **タスクトレイ常駐＆定周期実行の安定化**
  バックグラウンドにスマートに常駐し、指定した時間（定周期）ごとに自動でフォルダを監視・整理整頓します。
- **デイリーバックアップ機能**
  大切なファイルを誤って紛失しないよう、安全性を第一に考えた堅牢な設計になっています。
- **現代のOSへの最適化**
  前作の軽快な動作思想はそのままに、最新のPC環境でもより安定して高速に動作するよう内部システムを全面刷新しました。
