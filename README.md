# ClassiNy2（クラシニー2）

**★メールの振り分け感覚で、デスクトップやダウンロードフォルダを全自動で美しく★**

Winny全盛の時代に『メールの振り分けと同じ感覚で、大量のファイルもサクッと振り分け』のコンセプトでリリースされた ClassiNy の正統後継版、それが ClassiNy2 です。現代のPC環境に合わせてゼロから構築し直し、丸っきり別物として正統進化させました！

　
## 🚀 ご紹介

- **シンプル設定・直感的な簡単操作**
  
  メールの仕分けルールを作るような感覚で、ファイル名に含まれるキーワードや拡張子を登録するだけ。サクッとコピーや移動を実行できます。フォルダ構造を維持したままの振り分けにも対応しています。
  
- **【新機能】ドラッグ＆ドロップでその場でお片付け「選択モード」**
  
  予め決めておいたフォルダの中のファイルだけでなく、手動で今すぐ片付けたい時のための「選択モード」を新搭載。専用エリアにファイルやフォルダをドラッグ＆ドロップするだけで、指定したファイルだけを狙って瞬時に仕分けられます。
  
- **失敗しても安心！強力な「振り分け履歴＆元に戻す」機能**

  自動仕分けソフトは便利だけど、設定を間違えてファイルが迷子になったら怖い……　ClassiNy2 はそんな不安を解消するため、万が一、想定外のフォルダに振り分けられてしまっても「振り分け履歴から簡単に元の場所へ一括復元」できる唯一無二のリカバリ機能を搭載しています。
  
- **世代管理も万全「デイリーバックアップモード」**
  振り分け処理を実行した日付・時刻に基づいた名前のフォルダを自動で生成し、そこへファイルを格納します。日々の開発で更新されるソースコード、写真データや日次の業務書類など、手軽に「日別の世代バックアップ」を取りたい方に最適です。

- **バックグラウンドで全自動「定周期実行」**
  タスクトレイに常駐し、あらかじめ設定した時間間隔（周期）で自動的に巡回・振り分け処理を実行します。一度設定すれば、PCの中が勝手に毎日綺麗に保たれます。

- **パワーユーザー向け「条件のCSVエクスポート/インポート」**
  設定した振り分け条件をCSVファイルとして書き出し・読み込みが可能です。大量の条件を一括で登録したい場合、使い慣れたExcelやテキストエディタを使って効率よく編集できます。
